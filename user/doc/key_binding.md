# Key Binding

[→: Help Mode | ←: Warning Message]
[↑, PgUp: Scroll up | ↓, PgDn: Scroll down]
[Esc: Exit menu]

This is a brief list of key bindings (keyboard | joypad). Full help is available off-line (doc/wiki/) or on-line (https://github.com/Bozar/the-life-of-a-government-clerk/wiki).

## Normal Mode

* [Arrow keys | D-pad]: Move PC.
* [Space | Xbox A]: Switch to Examine Mode.
* [X | Xbox X]: Switch to Help Mode.
* [Z | Xbox Y]: Open Challenge List Menu.
* [C]: Open Help Menu.
* [V]: Open Debug Menu.
* [Enter | Xbox Menu]: Start new game.
* [Ctrl + W]: Quit game.

## Examine Mode, Help Mode

* [Arrow keys | D-pad]: Move cursor.
* [Esc | Xbox B]: Exit to Normal Mode.

## Wizard Key

* [1]: Clean all Carts.
* [2]: Reset all Raw File Node cooldowns.
* [3]: Add 1 Cash.
* [4]: Add 3 Carts.
* [5]: Add 1 Document.
* [6]: Show full map.
